# Finance Tracker

**Személyes pénzügyi nyilvántartó és elemző rendszer.**

A Finance Tracker egy egyetemi szakdolgozat keretében fejlesztett alkalmazás, amely a személyes bevételek és kiadások nyilvántartását, elemzését és vizualizációját teszi lehetővé.

A projekt célja, hogy a hagyományos pénzügyi nyilvántartást intelligens funkciókkal egészítse ki.

## Főbb funkciók

- Bevételek és kiadások kezelése
- Automatikus tranzakciókategorizálás
- CSV-alapú tranzakcióimport
- Pénzügyi statisztikák és kimutatások
- Szokatlan költések felismerése
- Kiadások előrejelzése
- Költségkeretek kezelése

## Technológiák

- **Backend:** C#, ASP.NET Core Web API
- **Frontend:** Blazor
- **Adatbázis:** SQL Server
- **Adatfeldolgozás:** ML.NET, Entity Framework Core

## Architektúra

A rendszer Clean Architecture és Domain-Driven Design (DDD) elvek alapján, moduláris monolit architektúrában készül.
